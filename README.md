Madrid Web Dev Website
======================

Creado con [Sculpin](http://sculpin.io)
y [Sculpin Blog Skeleton](https://github.com/sculpin/sculpin-blog-skeleton)

Se utilizan archivos estáticos Markdown (.md) para el contenido. No necesitamos más funcionalidad.

El proposito del sitio es publicar los eventos de Madrid Web Dev y tener por otro lado entradas de blog para extender cualquier tema.

Sería ideal en el futuro publicar los eventos en formato json siguiendo el formato de [Open Tech Events](https://github.com/OpenTechEvents/opentechevents-spec).
