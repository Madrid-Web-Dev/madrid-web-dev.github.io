Puede que tengas tu propio entorno de desarrollo con contenedores docker y/o máquinas virtuales o incluso ya estés usando DDEV pero tienes curiosidad sobre como te puede facilitar más el desarrollo local. O incluso quieres aprender a adaptarlo para ese extraño proyecto que tiene unos requisitos peculiares. Si es así ¡esta sesión te puede interesar!

DDEV es un entorno de desarrollo local multiplataforma que cubre una gran cantidad de tecnologías y tipos de proyecto.
Una instalación de DDEV ya viene configurada con muchas útilidades como por ejemplo certificados SSL locales y la habilidad de compartir tu proyecto local con internet.

Lo que vamos a cubrir:

- ¿Qué es DDEV? ¿Qué problema intenta resolver?
- ¿Qué archivos necesito añadir a un projecto que use DDEV? ¿Qué estructura siguen?
- Herramientas similares: Lando, docker compose, etc.
- Repaso de comandos DDEV y cómo añadir más comandos custom.
- Cambiar versiones de software instalada: PHP, nodeJS, cambiar nginx por apache o entre MySQL y MariaDB.
- Añadir servicios extra como Redis, SOLR o Varnish. También herramientas de testing y desarrollo como playwrighto Claude Code.
- Comenzar proyectos con DDEV. Ejemplo con Drupal CMS y Wordpress. Podemos explorar más como SvelteKit o TYPO3 si el tiempo lo permite.

La sesión se puede seguir en vivo si traes tu propio pórtatil con docker instalado (usando WLS2 en caso de Windows).

consolidando todo el ecosistema a través de múltiples tecnologías.
